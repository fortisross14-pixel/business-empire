# Batch 11A — GUI Visual Foundation

Scope: presentation only. No simulation, save-schema, product-engine, logo-system, product-art-system or campus-art changes.

## Visual direction
- Dark navy tycoon-game chrome with bright information surfaces.
- Compact top HUD for company identity, Cash, Profit / Q, Revenue / Q, Share, simulation speed and date.
- Persistent bottom dock as the primary quick-navigation affordance.
- Strong active states, compact contextual tabs and a game-style More sheet.
- White/blue content cards with consistent depth, spacing and status colors.
- Responsive treatment for tablet/mobile HUD and navigation.

## Screens touched
- Global shell / HUD / dock / More navigation.
- Shared Panel, Stat, ChoiceCard, Seg and input visual language.
- Home / new-company setup presentation.
- Products portfolio pulse presentation.
