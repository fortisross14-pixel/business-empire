# Batch 11C — Product Icon Depth + Competitor Identity

## Goal
Push the identity system beyond brand logos by making:
1. product packages more archetype-specific, and
2. competitor companies feel like recognizable rivals instead of plain text labels.

## Implemented

### 1) Deeper product icon coverage
Extended the reusable product visual system so current archetypes have clearer packaging language.

#### Skincare
- moisturizer → jar
- anti-aging / eye care → premium jar
- serum → dropper bottle
- sunscreen / acne / hydration / cleanser → tube-oriented pack
- face mask → pouch / sachet

#### Toys
- action figure → blister card
- building set → construction set box
- board game → board-game box
- plush → plush silhouette
- doll → window doll box
- vehicle → vehicle pack
- collectible → collectible box / capsule feel
- electronic toy → electronics box

### 2) Package structure logic
Each product visual keeps a systemic structure:
- base pack shape by archetype
- brand strip / brand color treatment
- optional IP sticker overlay
- quality frame / finish treatment
- light packaging-tone influence (premium / bold / techy / natural / retro etc.)

This means the game can scale by data instead of custom art per SKU.

### 3) Competitor logo system
Added derived competitor identity that uses:
- competitor name
- personality (premium / balanced / discounter)
- flagship category

The system generates:
- logo palette
- shape language
- motif language
- reusable competitor mark / chip / card

### 4) UI integration
Competitor identity is now visible in:
- Business Portfolio cards
- Market → Competitive Landscape
- Intelligence → Competitor Benchmark

## Why this matters
This moves the project further away from dashboard text and closer to a shelf / tycoon feel:
- products are more readable at a glance
- rival companies look like actual rival brands
- future categories/industries can plug into the same identity framework

## Not included yet
- map/campus visual pass
- region / geography view
- fully manual freeform vector editor for logos (still a systemic recipe-based identity tool)
